Chatbot con Streamlit

Este proyecto es una aplicación web construida con **Streamlit** durante un curso de IA y Python que implementa un chatbot interactivo.  
El objetivo es demostrar cómo se puede integrar un modelo de lenguaje o reglas de conversación dentro de una interfaz web sencilla y atractiva.



Características

- Interfaz web desarrollada en **Streamlit**.  
- Chat interactivo con almacenamiento del historial de conversación.  
- Diseño simple y minimalista.  
- Fácil de ejecutar en local o desplegar en la nube.  



Tecnologías utilizadas

- Python 3.13 
- Streamlit
- Groq
